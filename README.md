# Публичный чат на GitHub Pages (без Telegram)

Всё работает на статике GitHub Pages. Транспорт сообщений — публичный
брокер https://ntfy.sh (бесплатно, без ключей, без регистрации).

## Что умеет
- Имя до 20 символов, вход в общий чат.
- Все видят сообщения всех: имя, текст, время.
- Текст, фото (≤10 МБ), голосовые (≤5 МБ), видео и кружки (≤20 МБ).
- Пользователь `[bot] Крашер` — особый участник с префиксом `[bot]`.
  Писать можно ему (упоминанием), он пишет всем.
- 20 кликов по сообщению Крашера → открывается его профиль,
  интерфейс становится «мрачным»; кнопка «Выйти из профиля» возвращает норм.
- Первый вход просит только имя.
- «Очистить» — чистит только локальную копию.
- «Выйти» — сбрасывает sid и имя, перезагружает страницу.
- Ограничение: не более 5 отправок за 10 секунд.
- HTML не вставляется — только textContent.
- Медиа грузятся напрямую в ntfy с ограничением размера.

## Как выложить
1. Создать репозиторий на GitHub.
2. Положить `index.html` в корень.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/`.
4. Открыть `https://USERNAME.github.io/REPO/`.

## Как проверить
1. Открыть сайт, ввести имя — попадаете в чат.
2. Отправить текст — видно у всех, кто открыл сайт.
3. Отправить фото ≤10 МБ — отображается картинкой.
4. Голосовое ≤5 МБ — плеер.
5. Видео/кружок ≤20 МБ — видеоплеер.
6. Нажать 20 раз на сообщение Крашера — открывается профиль, фон мрачнеет.
   «Выйти из профиля» — возвращается.
7. «Очистить» — лог пуст только у вас.
8. «Выйти» — снова спрашивает имя.

## Ограничения честно
- ntfy.sh — публичный сервис, топик общий. Не пишите туда приватное.
- Если нужно приватно — поднимите свой ntfy-сервер и замените `NTFY`.
- Модерации нет: любой может писать. Ограничение частоты — на клиенте.
